# Simple Interest Calculator

## Project Description
This project is a simple interest calculator developed using a Bash script. It calculates simple interest based on the principal amount, rate of interest, and time period.

## Features
- Takes principal amount as input.
- Takes rate of interest as input.
- Takes time period as input.
- Calculates simple interest.
- Displays the calculated result.

## Formula
Simple Interest = (Principal × Rate × Time) / 100
